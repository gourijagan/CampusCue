# 🎓 CampusCue
### *Never miss a campus event.*

> **A centralized campus event discovery, registration, coordination, and seating management platform.**

---

## 📌 About the Project

**CampusCue** is a full-stack campus event management system designed to bring college events, registrations, coordination, and seating management into a single platform.

The system allows students to discover upcoming campus events, view detailed event information, register individually or as a team, and select seats for events with configured seating.

Faculty and authorized administrators can create and manage events, configure seating arrangements, view registrations, and assign student coordinators.

The goal of CampusCue is to make campus event management **simpler, organized, and accessible** for both students and faculty.

### 👨‍🏫 Faculty & Admin Features

- 🏢 Department-based event management

- 📋 View event registrations
